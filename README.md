# 📊 Credit Risk Analysis & Prediction

## 📌 Project Overview

This project focuses on analyzing customer financial data and predicting credit risk using Machine Learning techniques. It also includes SQL-based analysis and an interactive dashboard for business insights and decision-making.

---

## 🎯 Objectives

* Predict whether a customer is high risk or low risk
* Identify key factors affecting credit risk
* Perform SQL-based financial analysis
* Build a dashboard for visualization and insights

---

## ❗ Problem Statement

Financial institutions face challenges in identifying high-risk customers. Incorrect risk prediction can lead to financial losses. This project aims to build a reliable system to classify customers based on their credit risk.

---

## 📂 Dataset Description

| Column                  | Description                             |
| ----------------------- | --------------------------------------- |
| age                     | Age of the customer                     |
| gender                  | Gender of the customer                  |
| annual_income           | Annual income of the customer           |
| employment_status       | Employment type                         |
| credit_score            | Creditworthiness score                  |
| loan_application_amount | Loan amount requested                   |
| total_outstanding_debt  | Total debt                              |
| late_payment_count      | Number of late payments                 |
| fraud_flag              | Indicates fraud history                 |
| credit_risk             | Target variable (1 = Risk, 0 = No Risk) |

## 🔑 Key Insights

* Customers with low credit scores are high risk
* High debt leads to increased credit risk
* Late payments strongly impact risk classification
* Income and employment status influence risk levels

---

## 💡 Business Recommendations

* Avoid approving loans for high-risk customers
* Monitor customers with high outstanding debt
* Improve credit scoring strategies
* Offer financial planning support to risky customers
